# ImageData の全フォーマットとエラーパスのテストカバレッジを拡大する

Created: 2026-07-21
Model: Qwen Code

## 概要

テストが I420 フォーマットのみをカバーしており、公開 API の大部分にテストが存在しない。エラーパス・境界値のテストも欠如している。

## 根拠

### ImageData の 7/8 variant が未テスト

`ImageData` は 8 variant（I420, Yv12, Nv12, I422, I444, I42016, I42216, I44416）を公開しているが、テストで使われているのは I420 のみ（`tests/test_roundtrip.rs` 全体）。YV12 の U/V 入れ替わりバグ（0015）が検出されていない原因でもある。

### デコーダーのエラーパスが未テスト

- `decode()` を `next_frame()` 未完了状態で呼ぶ（iter ガード）
- `finish()` を `next_frame()` 未完了状態で呼ぶ（iter ガード）
- 不正なビットストリームデータを `decode()` に渡す
- 空スライスを `decode()` に渡す

### エンコーダーの検証エラーパスが未テスト

- フォーマット不一致時にエラーを返す検証（`src/lib.rs:2163-2170`）
- プレーンサイズ不正時にエラーを返す検証（`src/lib.rs:2175-2210`）

### DecodedFrame の U/V 系メソッドが未テスト

`u_plane()`, `v_plane()`, `u_stride()`, `v_stride()`, `format()`, `is_high_depth()` は公開 API だが、テストから直接呼ばれていない。

### 境界値テストが欠如

テストされる解像度は 64x64, 160x120, 320x240, 640x480 の 4 種類のみ。最小解像度（2x2）、奇数幅・奇数高さ（`div_ceil` パス）、幅/高さ 1 が未検証。

### EncoderConfig の 60 以上の Option フィールドのうち 15 程度しか未テスト

`apply_controls` の各分岐の大部分が 1 度も実行されていない。

## 修正方針

- 各 ImageData variant のラウンドトリップテストを追加する
- デコーダー/エンコーダーのエラーパステストを追加する
- DecodedFrame の U/V 系メソッドのテストを追加する
- 境界値テスト（奇数サイズ・最小解像度）を追加する
- テストファイルのモジュール分割を検討する（`tests/roundtrip.rs`, `tests/reconfigure.rs`, `tests/error_paths.rs` 等）

## 依存 issue

- **0015**（YV12 U/V 入れ替わり修正）が先に適用されること。YV12 のテストは修正後の動作を検証する

## 後方互換

テストの追加のみ。公開 API の変更なし。
